# Support

Use GitHub issues for reproducible bugs and feature requests. For setup problems include your OS/architecture, Node and Junior versions, the command used, and redacted `junior doctor` output. State whether the run was mocked or live and include a minimal task contract with workspace paths anonymized.

Never post API keys, authentication files, full private transcripts, or proprietary source. Review logs before attaching them. Read the README for installation, Jev modes, deadlines, and handoff review. This is a community project with no guaranteed support response time.
