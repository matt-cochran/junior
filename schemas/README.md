# Vendored schemas

`crossmatrix-dimensions.schema.json` is copied verbatim from
[praxec/crossmatrix](https://github.com/praxec/crossmatrix) `schemas/` at commit
`c58a5d8` (branch `dev`, ADR-0004 Dimensions layer). Junior's matrix adapters
emit documents that validate against it. Refresh it when Crossmatrix changes the
Dimensions schema.
